Boolean Simplifier

พิมพ์สูตร หรือแนบรูปสมการ แล้วให้เว็บช่วยอ่านและย่อให้อยู่ในรูป SOP ที่สั้นลง พร้อมรองรับสัญลักษณ์ Boolean หลายรูปแบบ

INPUT

ใส่สมการ

+ / ∨ OR * / ∧ AND X' / X̅ NOT ⊕ / ^ XOR ⊙ XNOR
ตัวแปรไม่ล็อก A/B: ใช้ X, Y, Z, Q1, Sensor, Input_A ได้เลย และถ้าต้องการชื่อพิมพ์ใหญ่หลายตัว เช่น INPUT ให้เขียน [INPUT]
หรือ
OCR ยังไม่ได้เลือกรูป

บนคอมกด Ctrl + Enter เพื่อย่อได้ทันที

RESULT

ผลลัพธ์

01

ใส่สูตรหรืออ่านข้อความจากรูป แล้วกด ย่อสมการ

สมการที่ย่อแล้ว
โปรแกรมตีความสูตรเป็น
วิธีที่ใช้

สร้าง Truth Table → หา minterm → Quine–McCluskey → เลือกชุด Prime Implicant ที่ใช้จำนวนพจน์น้อยที่สุด และใช้ literal น้อยกว่าเมื่อจำนวนพจน์เท่ากัน

SYNTAX

สัญลักษณ์พิเศษใส่ยังไง

X
NOT / Bar ตัวเดียว X̅ หรือ X', !X, ¬X
X + Y
Bar ยาวครอบทั้งกลุ่ม BAR(X+Y) เหมือน (X+Y)'
X ⊕ Y
Exclusive OR X ⊕ Y หรือ X ^ Y, X XOR Y
X ⊙ Y
Exclusive NOR X ⊙ Y หรือ X XNOR Y

ตัวอย่างการย่อ

CD + CD'→C
X ⊕ Y→X'·Y + X·Y'
BAR(X+Y)→X'·Y'
Sensor*Enable + Sensor*Enable'→Sensor
[INPUT]*Q1 + [INPUT]*Q1'→[INPUT]

รองรับได้สูงสุด 8 ตัวแปรต่อสูตร เพื่อให้การสร้าง Truth Table และการย่อทำงานเร็วในเบราว์เซอร์ รูปที่พิมพ์หรือเขียนชัดจะ OCR ได้ดีที่สุด โดยเฉพาะเส้น Bar จากลายมืออาจถูก OCR มองข้าม จึงมีปุ่ม BAR ให้กดเพิ่มหรือแก้สูตรก่อนย่อได้
