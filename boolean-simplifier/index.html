วิธีที่ใช้

สร้าง Truth Table → หา minterm → Quine–McCluskey → เลือกชุด Prime Implicant ที่ใช้จำนวนพจน์น้อยที่สุด และใช้ literal น้อยกว่าเมื่อจำนวนพจน์เท่ากัน

ตัวอย่างที่รองรับ

AB + AB' → A A + AB → A (A+B)(A+B') → A

รองรับตัวแปร A–Z สูงสุด 8 ตัวต่อสูตร รูปที่เป็นตัวพิมพ์หรือเขียนชัดจะอ่านได้ดีกว่าลายมือที่ซ้อนกัน หาก OCR อ่านผิดสามารถแก้สูตรในช่องข้อความก่อนย่อได้
