คู่มือการใช้งาน

วิธีพิมพ์สมการ ใช้ Bar/XOR/XNOR อ่านจากรูป และเข้าใจว่ารูปแบบไหนที่ OCR รองรับในตอนนี้

หัวข้อ เริ่มใช้งาน สัญลักษณ์ ตัวแปร รูปและกล้อง หลายข้อในรูปเดียว ทดสอบรูปวงจร ข้อจำกัด
01 • START

เริ่มใช้งาน

  1. ไปหน้า คำนวณ แล้วพิมพ์สูตร หรือเลือก เลือกรูป / ถ่ายรูป
  2. ถ้าใช้รูป ให้กด อ่านข้อความจากรูป และตรวจข้อความที่ OCR อ่าน โดยเฉพาะ Bar
  3. กด ย่อสมการ โปรแกรมจะสร้าง Truth Table และหา Minimal SOP
A*B + A*B'→A
02 • SYNTAX

สัญลักษณ์ที่รองรับ

ความหมายพิมพ์ได้ตัวอย่าง
AND* . · ∧ หรือเขียนติดกันA.B, AB
OR+ ∨A+B
NOT ตัวเดียวA' A̅ !A ¬AA
Bar ครอบกลุ่มBAR(A+B) หรือ (A+B)'A+B
XOR⊕ ^ หรือ XORA⊕B
XNOR⊙ หรือ XNORA⊙B
03 • VARIABLES

ตัวแปรไม่ล็อก A/B

ใช้ชื่ออย่าง W, X, Q1, Sensor, Input_A ได้ และถ้าต้องการชื่อพิมพ์ใหญ่หลายตัวให้ครอบด้วย [ ] เช่น [INPUT]

[INPUT]*Enable + [INPUT]*Enable'→[INPUT]

ใส่ชื่อเอาต์พุตได้ด้วย เช่น F1 = A+B โปรแกรมจะย่อเฉพาะด้านขวาและเก็บ F1 = ไว้

04 • IMAGE OCR

เลือกรูปกับถ่ายรูปแยกกัน

▣ เลือกรูป

เลือก JPG/PNG/ภาพจาก Photos หรือ Files โดยไม่บังคับเปิดกล้อง

◉ ถ่ายรูป

บนมือถือจะขอเปิดกล้องด้านหลังเพื่อถ่ายโจทย์ใหม่

OCR ใช้ Tesseract อ่านตัวอักษร และมี Bar Detector (Beta) ที่ใช้ตำแหน่งตัวอักษรกับเส้นแนวนอนในภาพเพื่อพยายามสร้าง BAR(...)

สำคัญ: ตรวจสูตรที่ OCR อ่านก่อนย่อเสมอ โดยเฉพาะภาพเบลอ เอียง มีเส้นตาราง หรือ Bar ซ้อนหลายชั้น
05 • BATCH

หลายข้อในรูปเดียว

ถ้า OCR อ่านออกมาเป็นหลายบรรทัด เช่น 1. X=..., 2. Z=... โปรแกรมจะแยกแต่ละข้อและแสดงผลเป็นรายการ

1. X = AB + AB'
2. Z = A + A'
3. Y = BAR(A+B)
06 • CIRCUIT TEST

ทดสอบกับรูปวงจร Logic Gate

รูปวงจรที่ใช้ทดสอบมีอินพุต w,x,y,z และจุดกลาง T1–T4. ตอนนี้ OCR ของโปรแกรมออกแบบมาสำหรับ รูปสมการ จึงยังไม่สามารถตามเส้นและจำแนก Gate จากรูปวงจรอัตโนมัติได้ แต่เมื่อถอดวงจรเป็นสูตรแล้ว ตัว Simplifier คำนวณได้ถูกต้อง:

T1 = X'YT1 = X'·Y
T2 = W'XT2 = W'·X
T3 = W + X'YT3 = W + X'·Y
T4 = (W'X) XOR ZT4 = X'·Z + W'·X·Z' + W·Z
F1 = W + X'Y + ((W'X) XOR Z)F1 = W + X'·Y + X'·Z + X·Z'
F2 = W'X + ZF2 = Z + W'·X
ผลทดสอบ: ส่วนย่อสมการผ่านเคสวงจรนี้ แต่การแปลง “ภาพ Gate → สูตร” เป็นฟีเจอร์คนละชุดกับ OCR สมการ และยังไม่ได้เปิดใช้งานในเวอร์ชันนี้
07 • LIMITS

ข้อจำกัดปัจจุบัน

  • สูงสุด 8 ตัวแปรต่อหนึ่งสมการ เพื่อควบคุมขนาด Truth Table
  • คำตอบหลักเป็น Minimal SOP; รูป factor เช่น A(B+C) อาจไม่ได้สั้นที่สุดในแง่จำนวนตัวอักษร
  • Bar Detector เป็น Beta และอาจผิดเมื่อภาพคุณภาพต่ำ
  • ยังไม่รองรับการอ่าน Logic Gate Diagram เป็นสมการอัตโนมัติ
