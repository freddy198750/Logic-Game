Boolean Simplifier
คำนวณ คู่มือ
DOCUMENTATION

คู่มือการใช้งาน

สัญลักษณ์ วิธีพิมพ์สูตร การใช้รูป และข้อจำกัดของระบบ

หัวข้อ เริ่มใช้งาน สัญลักษณ์ ตัวแปร รูปและกล้อง หลายข้อ วงจร ข้อจำกัด
01 • START

เริ่มใช้งาน

  1. ไปหน้า คำนวณ แล้วพิมพ์สูตร หรือเลือก เลือกรูป / ถ่ายรูป
  2. รูปสมการให้กด อ่านข้อความ; รูป Logic Gate ให้กด วิเคราะห์วงจร
  3. สูตรที่พิมพ์หรือ OCR แล้วกด ย่อสมการ เพื่อหา Minimal SOP
A*B + A*B'→A
02 • SYNTAX

สัญลักษณ์ที่รองรับ

ความหมายพิมพ์ได้ตัวอย่าง
AND* . · ∧ หรือเขียนติดกันA.B, AB
OR+ ∨A+B
NOTA' A̅ !A ¬AA
Bar ครอบกลุ่มBAR(A+B) หรือ (A+B)'A+B
XOR⊕ ^ หรือ XORA⊕B
XNOR⊙ หรือ XNORA⊙B
03 • VARIABLES

ตัวแปร

ใช้ W, X, Q1, Sensor, Input_A ได้ ถ้าต้องการชื่อพิมพ์ใหญ่หลายตัวให้ใช้ [INPUT]

[INPUT]*Enable + [INPUT]*Enable'→[INPUT]

ใส่ชื่อเอาต์พุตได้ เช่น F1 = A+B โปรแกรมจะย่อเฉพาะด้านขวา

04 • IMAGE

รูปและกล้อง

▣ เลือกรูป

เลือก JPG/PNG จาก Photos หรือ Files

◉ ถ่ายรูป

เปิดกล้องด้านหลังบนมือถือเพื่อถ่ายโจทย์ใหม่

อ่านข้อความ ใช้กับรูปสมการ Boolean ส่วน วิเคราะห์วงจร ใช้กับภาพ Logic Gate Diagram

โหมดรูปยังเป็น Beta: ภาพที่คม ตรง พื้นหลังเรียบ และสายส่วนใหญ่แนวนอน/แนวตั้งจะอ่านได้ดีที่สุด
05 • BATCH

หลายข้อในรูปเดียว

ถ้า OCR อ่านได้หลายบรรทัด โปรแกรมจะแยกและย่อทีละข้อ

1. X = AB + AB'
2. Z = A + A'
3. Y = BAR(A+B)
06 • CIRCUIT BETA

Logic Gate Diagram

เลือกภาพวงจรแล้วกด วิเคราะห์วงจร โปรแกรมจะพยายามหา Gate, ตามสาย, แยกจุดต่อกับจุดตัด และสร้างสมการเอาต์พุตก่อนส่งไปยัง Boolean Simplifier

เวอร์ชันนี้เน้นภาพตำรา/สแกนที่ใช้ NOT, AND, OR, XOR และสายชัดเจน

T1 = X'YT1 = X'·Y
T2 = W'XT2 = W'·X
T3 = W + X'YT3 = W + X'·Y
T4 = (W'X) XOR ZT4 = X'·Z + W'·X·Z' + W·Z
F1 = W + X'Y + ((W'X) XOR Z)F1 = W + X'·Y + X'·Z + X·Z'
F2 = W'X + ZF2 = Z + W'·X
07 • LIMITS

ข้อจำกัด

  • สูงสุด 8 ตัวแปรต่อหนึ่งสมการ
  • คำตอบหลักเป็น Minimal SOP
  • Bar Detector ยังเป็น Beta
  • Circuit Analyzer ยังเป็น Beta และเน้น NOT/AND/OR/XOR; รูปเอียง ลายมือ เส้นโค้งมาก หรือ NAND/NOR/XNOR อาจยังอ่านผิด
